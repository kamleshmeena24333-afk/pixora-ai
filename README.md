# 🎨 Pixora AI — Generative AI Image Platform

Pixora AI is a modern, responsive web application designed for generative AI image synthesis, photo enhancements, and prompt-based workflows.

## 🚀 Features
- **Prompt Generator Studio:** Multi-ratio & style preset generator UI.
- **Credit Balance System:** Simulated dynamic token management.
- **AI Tool Suite:** Background removal, color enhancement, and 4K upscaler modules.
- **Responsive Dark Theme:** Built with Tailwind CSS & Glassmorphic accents.
